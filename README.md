# Xtream Player Pro

## Overview
Xtream Player Pro is a dedicated media player application designed for streaming content from Xtream API services. This application provides a user-friendly interface for accessing and enjoying your IPTV content.

## Features
- Stream live TV channels
- Watch VOD (Video on Demand) content
- EPG (Electronic Program Guide) integration
- User-friendly interface
- Credential management
- Customizable playback settings

## Installation
1. Download the latest release from the [Releases](https://github.com/yourusername/xtream-player-pro/releases) page
2. Extract the ZIP file to your preferred location
3. Run the `Xtream Player Pro.exe` file to start the application

## Configuration
Upon first launch, you'll need to enter your Xtream API credentials:
1. Open the application
2. Enter your server URL, username, and password
3. Click "Save" to store your credentials

## System Requirements
- Windows 7/8/10/11
- .NET Framework 4.5 or higher
- Minimum 2GB RAM
- 100MB free disk space
- Internet connection
